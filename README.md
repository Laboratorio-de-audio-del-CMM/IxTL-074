# IxTL-074

El IxTL-074 es un sintetizador semimodular DIY de bajo costo desarrollado en el Laboratorio de Experimentación Sonora del Centro Multimedia entre agosto y octubre del 2026. Se compone de cuatro osciladores de onda cuadrada especializados en distintas frecuencias:

* Oscilador 1: 1.7-140 Hz aproximadamente
* Oscilador 2: 6.5-463 Hz aproximadamente
* Oscilador 3: 137-2266 Hz aproximadamente
* Oscilador 4: 147-5848 Hz aproximadamente

La frecuencia y amplitud de cada oscilador puede ser controlada mediante dos perillas, especificadas en la placa como "frec" y "amp".

Cada oscilador posee tres salidas y tres entradas. 

Las salidas corresponden a la frecuencia y amplitud especificadas con las perillas. Pueden usarse como salidas de audio cuando se conectan a la mezcladora, o como frecuencias de modulación cuando se conectan a las entradas de otro oscilador (o incluso a su propia entrada).

Las entradas modulan la frecuencia de cada oscilador.

Las conxiones entre salidas, entradas y mezcladora se establecen utilizando cables dupont (también conocidos como "jumpers"). 

El sinteizador funciona con una fuente de alimentación de 9v con punta positiva. 

Es un sintetizador monofónico y posee salida de audio estéreo (soble mono) de jack de 3.5mm.
